How to Use the Optimizer
Quick Start
  1. Select your database engine from the dropdown
  2. Click "Load Sample Data" to see how the tool works with example queries
  3. Or enter your own SQL query in the SQL Query section
  4. Add table and index information for better analysis
  5. Paste your EXPLAIN plan or use the "How to Generate EXPLAIN Plan" guide
  6. Click "Analyze Query" to get optimization recommendations
