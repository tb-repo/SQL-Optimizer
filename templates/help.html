Quick Start Guide

Back to Top

Follow these simple steps to analyze your SQL query and get performance recommendations:

1
Enter Your SQL Query

Paste your SQL query into the main text area. The app supports all major SQL dialects including SELECT, INSERT, UPDATE, DELETE statements.

SELECT u.name, p.title, c.comment
FROM users u
JOIN posts p ON u.id = p.user_id
LEFT JOIN comments c ON p.id = c.post_id
WHERE u.active = 1 AND p.published = 1;
2
Add Table Information (Optional but Recommended)

For more accurate analysis, provide your table structures. Click the "Add Table" button to add each table:

  • Table Name - The name of your table
  • DDL - CREATE TABLE statement or table structure
  • Row Count - Approximate number of rows (helps with optimization decisions)
  • Size - Table size (e.g., 500MB, 2GB, 1.5TB)
CREATE TABLE users (
  id INT PRIMARY KEY,
  name VARCHAR(100),
  email VARCHAR(255) UNIQUE,
  active BOOLEAN DEFAULT true
);
Adding Multiple Tables

Click the "Add Table" button multiple times to add information for all tables in your query. Each table will appear as a separate form section.

3
Add Index Information (Optional)

Include your existing indexes to get better recommendations. Click the "Add Index" button for each index:

  • Index Name - Name of the index
  • Table - Table the index belongs to
  • Definition - Index definition or columns
  • Size - Index size (e.g., 50MB, 200MB)
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_posts_user_published ON posts(user_id, published);
Adding Multiple Indexes

Click the "Add Index" button multiple times to add information for all indexes. This helps the analyzer understand your current indexing strategy.

4
Add EXPLAIN Plan (Optional)

If you have an EXPLAIN plan from your database, paste it here for detailed analysis of the query execution plan.

Seq Scan on users (cost=0.00..431.00 rows=21000 width=4)
  Filter: (status = 'active')
5
Select Database Engine

Choose your target database engine from the dropdown. This ensures you get engine-specific optimization tips and syntax recommendations.

  • PostgreSQL - Advanced features, JSON support, complex queries
  • MySQL - Web applications, simple to complex queries
  • Oracle - Enterprise applications, complex business logic
  • SQL Server - Microsoft ecosystem, business intelligence
  • SQLite - Embedded applications, mobile apps
Engine-Specific Tips

The "Did You Know?" section will show different tips based on your selected database engine!

6
Analyze Your Query

Click the "Analyze SQL" button to get your comprehensive performance report.

Tips & Best Practices

Back to Top
Pro Tip: Use "Did You Know?" Section

Check out the rotating database-specific tips in the "Did You Know?" section. These contain valuable insights and best practices for your chosen database engine!

General SQL Optimization Tips:
  • Use indexes wisely - Index columns used in WHERE, JOIN, and ORDER BY clauses
  • Avoid SELECT * - Only select the columns you need
  • Limit result sets - Use LIMIT/TOP to restrict results
  • Optimize JOINs - Use appropriate JOIN types and ensure indexed columns
  • Use appropriate data types - Choose the right column types for your data
  • Consider query patterns - Design queries based on how they'll be used
Important Notes:
  • This tool provides recommendations based on static analysis. Always test changes in a development environment first.
  • Performance improvements depend on your specific data distribution and usage patterns.
  • Some recommendations may not apply to your specific use case - use your judgment.

Understanding Your Analysis Report

Back to Top

After analyzing your SQL query, you'll receive a comprehensive report with several sections:

📊
Summary Section

A high-level overview of your query analysis, highlighting key findings and potential issues.

Example: "Query uses SELECT *. No WHERE clause detected. Possible missing index on status column."
📋
Tables Section (if provided)

Shows the table information you provided, including structure, row counts, and sizes. This helps the analyzer understand your data context.

Collapsible Section

Click to expand/collapse the tables section to view detailed table information.

🔍
Indexes Section (if provided)

Displays your current indexing strategy. The analyzer uses this to suggest missing indexes or optimization opportunities.

Collapsible Section

Click to expand/collapse the indexes section to view detailed index information.

💡
Recommendations Section

Specific, actionable suggestions to improve your query performance. These are prioritized by potential impact.

Example: "Consider adding an index on column 'status' used in WHERE clause for better performance."
⚠️
Warnings Section

Potential performance issues or problematic patterns that could impact query performance.

Example: "Avoid using SELECT *. Specify only the columns you need for better performance."
🔧
Optimized Query Suggestion

A rewritten version of your query with performance improvements applied. This shows you exactly how to implement the recommendations.

Original: SELECT * FROM users WHERE status = 'active';
Optimized: SELECT id, name, email FROM users WHERE status = 'active';
📈
EXPLAIN Plan Visualization (if provided)

If you provided an EXPLAIN plan, this section shows a visual representation of how your database executes the query.

Visual Analysis

Use this to understand the query execution flow and identify bottlenecks in your database's processing.

📚
Recent Analyses History

Shows your last 5 analyses with the ability to re-run or edit previous queries. This helps you track your optimization progress.

History Features
  • Re-run Analysis: Execute the same analysis again
  • Edit: Modify the query and re-analyze
  • View Details: Expand to see full analysis results

Analytics Dashboard

Back to Top
Overview

The Analytics Dashboard provides comprehensive insights into your SQL query performance over time, helping you identify trends, patterns, and optimization opportunities.

Features
  • Performance Metrics: Average scores, complexity, and optimization potential
  • Database Distribution: See which database engines you use most
  • Complexity Analysis: Distribution of query complexity levels
  • Trend Visualization: Performance trends over time with interactive charts
  • Pattern Recognition: Common SQL patterns and usage statistics
  • Actionable Insights: AI-generated recommendations for improvement

How to Access
  1. Click the "Analytics" button on the main page or result page
  2. View comprehensive analytics after analyzing multiple queries
  3. Explore different chart sections for detailed insights
  4. Use insights to improve your query writing practices
Dashboard Sections
  • Key Metrics: Total analyses, average performance, complexity, and optimization potential
  • Actionable Insights: AI-generated recommendations based on your query patterns
  • Database Distribution: Pie chart showing your preferred database engines
  • Complexity Distribution: Bar chart of query complexity levels
  • Performance Trends: Line charts showing performance over time
  • Common Patterns: Statistics on SQL patterns like SELECT *, JOINs, aggregations
  • Performance Range: Best and worst performing queries
Insights Types
  • Performance Insights: Based on average scores and trends
  • Pattern Insights: Analysis of common SQL patterns and anti-patterns
  • Database Insights: Recommendations based on your primary database
  • Complexity Insights: Suggestions for managing query complexity

Query Comparison

Back to Top
Overview

The Query Comparison feature allows you to compare multiple SQL queries side-by-side, providing detailed performance analysis, rankings, and optimization recommendations.

Features
  • Multi-Query Analysis: Compare up to 5 queries simultaneously
  • Performance Rankings: See which queries perform best
  • Complexity Comparison: Compare query complexity scores
  • Resource Usage: Analyze memory and CPU usage differences
  • Optimization Potential: Identify which queries need optimization
  • Key Differences: Highlight significant performance gaps
  • Smart Recommendations: Get specific optimization advice
How to Use
  1. Click the "Compare" button on the main page or result page
  2. Enter 2-5 SQL queries you want to compare
  3. Select the appropriate database engine for each query
  4. Click "Compare Queries" to analyze
  5. Review the comprehensive comparison results
Comparison Results
  • Performance Rankings: Queries ranked by execution time and efficiency
  • Complexity Rankings: Queries ranked by complexity score
  • Key Differences: Highlighted performance gaps between queries
  • Recommendations: Specific optimization suggestions for each query
  • Interactive Charts: Visual comparison of performance metrics
  • Individual Analysis: Detailed breakdown for each query
Use Cases
  • Query Optimization: Compare different versions of the same query
  • Performance Testing: Test different approaches to the same problem
  • Code Review: Evaluate multiple query implementations
  • Learning: Understand performance differences between query patterns
  • Decision Making: Choose the best query for production use
